# 答辩 PPT 大纲（12 页）

> 风格建议：白底 + 简洁配色，每页不超过 30 字，**图多字少**，避免把 PPT 做成文档。

## 附：PPT 制作要点

1. **每页不超过 30 字**：评委看的是图和你的讲解，不是读你的 PPT
2. **截图优先于示意图**：真实的产品截图比画图更有说服力
3. **技术页控制在 3 页**（第 7/8/9），别陷入技术细节
4. **第 8 页「可靠性闭环」是重头戏**：这是你和其他参赛者拉开差距的地方，值得多讲
5. **配色统一**：建议用一套主题色（比如深蓝 + 白 + 一个强调色），别花哨
