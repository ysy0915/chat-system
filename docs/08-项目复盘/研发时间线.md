## 七、安全修复与自检（09-27）

- **订阅级鉴权落地**：`WebSocketConfig` 空实现 → `ChannelInterceptor` 真正拦截（私有 topic `/topic/user|debate|treehole.{id}` 仅 token 归属者可订阅，fail-close），堵住越权订阅他人私聊/树洞消息
- **/internal 共享令牌**：`InternalApiTokenFilter` + web 侧 RestTemplate 自动注入（`INTERNAL_API_TOKEN`，常量时间比较），内部接口双层防护
- **IP 防伪造**：`ClientIpResolver` 可信代理判定（仅内网/回环直连采信代理头），堵住伪造 X-Forwarded-For 绕过限流/登录锁定
- **启动自检**：`StartupConfigValidator`（密钥占位符 / 已启用 LLM api_key / tree_hole_messages schema 漂移，启动即打 ERROR 附修复 SQL/DDL）
- **cross-node 根治**：`CrossNodeExchangeDefaults` 无条件声明交换机，单机部署广播 channel error 归零
- CORS 白名单占位符清理为真实地址；`toInt` 重复实现收敛 `UsageJsonUtils`；新增 13 项安全单测（`WebSocketSubscriptionAuthTest` + `ClientIpResolverTest`）
