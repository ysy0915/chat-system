# 安全配置说明

> JWT 鉴权、接口白名单、IP 限流、内容安全的完整说明

---

## 一、安全体系总览

```
请求进入
    │
    ▼
IpRateLimitInterceptor (滑动窗口限流)
    ├─ 同 IP 短时间内请求过多 → 自动拉黑
    └─ UA 过滤可疑爬虫
    │
    ▼
JwtAuthenticationFilter (JWT 鉴权)
    ├─ 提取 Authorization: Bearer xxx
    ├─ 验证 JWT 签名和有效期
    └─ 未通过 → 401
    │
    ▼
ContentSafetyService (内容安全)
    └─ 阿里云内容安全检测 → 命中敏感词拒绝
    │
    ▼
业务 Controller
```

## 二、JWT 鉴权

### 2.1 配置

实现类：`chat-common/.../security/JwtUtil.java`

| 配置项 | 说明 |
|--------|------|
| Token 格式 | `Authorization: Bearer <token>` |
| 签名算法 | HMAC-SHA256 |
| Token 存储 | 前端 `localStorage.auth_token` |
| 密钥强度 | 必须 ≥ 32 字节（弱密钥拒绝启动，见 2.4） |

### 2.2 前端拦截

`main.jsx` 中全局 axios 401 拦截器：
```javascript
// 任意接口返回 401 时
axios.interceptors.response.use(
  response => response,
  error => {
    if (error.response?.status === 401) {
      localStorage.removeItem('auth_token');
      localStorage.removeItem('auth_user');
      window.dispatchEvent(new Event('auth-changed'));
    }
    return Promise.reject(error);
  }
);
```

### 2.3 登录拦截的页面

以下页面未登录时拦截导航，弹出登录框：
- `/personal` — 个人对话空间
- `/treehole` — 情绪树洞
- `/profile` — 个人信息

### 2.4 弱密钥校验（2026-08 新增）

`JwtUtil` 在启动时校验 `jwt.secret` 强度：**少于 32 字节直接抛 `IllegalStateException` 拒绝启动**，防止弱密钥被暴力破解。

```bash
# 生成符合要求的强密钥
openssl rand -base64 48
```

> 生产环境 `.env` 中 `JWT_SECRET` 需同步更新为 ≥32 字节（当前 40 字节，符合要求）。

## 三、接口白名单

实现类：`chat-common/.../config/SecurityConfig.java`

### 3.1 无需登录的公开接口

```java
// 认证相关
.requestMatchers("/api/v1/auth/**").permitAll()

// 公开群聊
.requestMatchers("/api/v1/messages/**").permitAll()

// 观点辩论场
.requestMatchers("/api/v1/debate/**").permitAll()

// 模型配置（公开只读）
.requestMatchers(HttpMethod.GET, "/api/v1/models/**").permitAll()

// 在线人数
.requestMatchers("/api/v1/online/**").permitAll()

// 监控面板（独立密码验证）
.requestMatchers("/api/v1/monitor/**").permitAll()

// SQL 执行器（独立 SQL_EXECUTOR_PASSWORD 密码验证 + 登录锁定 + 危险SQL拦截）
.requestMatchers("/api/v1/sql/**").permitAll()

// WebSocket
.requestMatchers("/ws/**").permitAll()

// 系统接口
.requestMatchers("/actuator/health").permitAll()
.requestMatchers("/api/v1/frontend-error").permitAll()

// 静态资源
.requestMatchers("/", "/index.html", "/chat/**", "/static/**").permitAll()
```

### 3.2 需要登录的接口

| 接口 | 说明 |
|------|------|
| `POST /api/v1/treehole/ask` | 情绪树洞（需要 JWT） |
| `GET /api/v1/treehole/history` | 树洞历史 |
| `GET /api/v1/users/me` | 用户信息 |
| `GET /api/v1/users/{id}/history` | 用户历史 |

### 3.3 管理员接口

```java
.requestMatchers("/api/v1/admin/**").hasRole("ADMIN")
```

## 四、限流机制

### 4.1 IP 访问限流（网关层）

实现类：`chat-common/.../interceptor/IpRateLimitInterceptor.java`

| 配置 | 说明 |
|------|------|
| 算法 | 滑动窗口 |
| 触发条件 | 同 IP 短时间大量请求 |
| 处理方式 | 自动拉黑 + UA 过滤（拦截可疑爬虫 UA） |

### 4.2 SQL 执行台限流（2026-08 新增）

实现类：`chat-games/.../SqlExecutorController.java`

| 配置 | 说明 |
|------|------|
| 登录失败锁定 | 同一 IP 连续失败 ≥ 5 次 → 锁定 15 分钟，返回 429 并提示剩余锁定分钟 |
| 执行频率 | 同一 IP 滑动窗口，每分钟最多 30 次 |
| 危险关键字 | 拦截 `OUTFILE` / `DUMPFILE` / `LOAD_FILE` / `SLEEP` / `BENCHMARK` 等 |
| 多语句 | 包含 `;` 的多语句直接拒绝 |

### 4.3 媒体生成限流（2026-08 新增）

实现类：`chat-media/.../MediaGenController.java`（`RateLimitService`）

| 配置 | 说明 |
|------|------|
| 限流维度 | 用户级（按 userId） |
| 处理方式 | 超限返回 429 + `retry_after`（重试等待秒数） |
| 覆盖接口 | 图片/视频/3D 等生成类接口 |

## 六、前端错误上报

实现类：`chat-common/.../controller/FrontendErrorController.java`

**接口**：`POST /api/v1/frontend-error` (无需登录)

**上报来源**：
1. `window.onerror` — 全局未捕获错误
2. `window.unhandledrejection` — 未处理的 Promise 拒绝
3. `ErrorBoundary.componentDidCatch` — React 渲染异常

**处理**：记录到后端日志 (WARN 级别)，带堆栈信息

## 七、密钥管理

| 密钥类型 | 存储方式 | 位置 |
|---------|---------|------|
| JWT 签名密钥 | 配置文件 | `application.yml` 或环境变量 |

| 数据库密码 | 环境变量 | `DB_USERNAME` / `DB_PASSWORD` in `.env` |

## 八、参数校验与上传限制（2026-08 新增）

### 8.1 DTO 参数校验

登录/注册等接口使用 `@Valid` + DTO（`LoginRequest` / `RegisterRequest`）统一校验：

| 校验项 | 规则 |
|-------|------|
| 用户名 | `@NotBlank`、`@Size(min=3, max=50)` |
| 密码 | `@NotBlank`、`@Size(min=6, max=50)` |
| 其他字段 | 按接口语义配置（邮箱格式、长度上限等） |

校验失败返回 400 + 具体字段错误，不再手写长度判断。

### 8.2 上传大小限制

全模块（chat-web / chat-core / chat-games / chat-media）统一配置：

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 10MB
      max-request-size: 10MB
```

超限请求返回 413，防止超大文件拖垮服务。

## 九、WebSocket 安全

- WebSocket 端点：`/ws/chat`
- 连接时携带 JWT (query param 或 STOMP header)
- 不需要额外鉴权（公开群聊的 WebSocket 也允许匿名连接）
- SockJS 心跳维持连接状态
