# 安全配置说明

> JWT 鉴权、接口白名单、IP 限流、内容安全的完整说明

---

## 一、安全体系总览

```
请求进入
    │
    ▼
IpRateLimitInterceptor (滑动窗口限流)
    ├─ 同 IP 短时间内请求过多 → 自动拉黑
    └─ UA 过滤可疑爬虫
    │
    ▼
JwtAuthenticationFilter (JWT 鉴权)
    ├─ 提取 Authorization: Bearer xxx
    ├─ 验证 JWT 签名和有效期
    └─ 未通过 → 401
    │
    ▼
ContentSafetyService (内容安全)
    └─ 阿里云内容安全检测 → 命中敏感词拒绝
    │
    ▼
业务 Controller
```

## 二、JWT 鉴权

### 2.1 配置

实现类：`chat-common/.../security/JwtUtil.java`

| 配置项 | 说明 |
|--------|------|
| Token 格式 | `Authorization: Bearer <token>` |
| 签名算法 | HMAC-SHA256 |
| Token 存储 | 前端 `localStorage.auth_token` |

### 2.2 前端拦截

`main.jsx` 中全局 axios 401 拦截器：
```javascript
// 任意接口返回 401 时
axios.interceptors.response.use(
  response => response,
  error => {
    if (error.response?.status === 401) {
      localStorage.removeItem('auth_token');
      localStorage.removeItem('auth_user');
      window.dispatchEvent(new Event('auth-changed'));
    }
    return Promise.reject(error);
  }
);
```

### 2.3 登录拦截的页面

以下页面未登录时拦截导航，弹出登录框：
- `/personal` — 个人对话空间
- `/treehole` — 情绪树洞
- `/profile` — 个人信息

## 三、接口白名单

实现类：`chat-common/.../config/SecurityConfig.java`

### 3.1 无需登录的公开接口

```java
// 认证相关
.requestMatchers("/api/v1/auth/**").permitAll()

// 公开群聊
.requestMatchers("/api/v1/messages/**").permitAll()

// 观点辩论场
.requestMatchers("/api/v1/debate/**").permitAll()

// 模型配置（公开只读）
.requestMatchers(HttpMethod.GET, "/api/v1/models/**").permitAll()

// 在线人数
.requestMatchers("/api/v1/online/**").permitAll()

// 监控面板（独立密码验证）
.requestMatchers("/api/v1/monitor/**").permitAll()

// WebSocket
.requestMatchers("/ws/**").permitAll()

// 系统接口
.requestMatchers("/actuator/health").permitAll()
.requestMatchers("/api/v1/frontend-error").permitAll()

// 静态资源
.requestMatchers("/", "/index.html", "/chat/**", "/static/**").permitAll()
```

### 3.2 需要登录的接口

| 接口 | 说明 |
|------|------|
| `POST /api/v1/treehole/ask` | 情绪树洞（需要 JWT） |
| `GET /api/v1/treehole/history` | 树洞历史 |
| `GET /api/v1/users/me` | 用户信息 |
| `GET /api/v1/users/{id}/history` | 用户历史 |

### 3.3 管理员接口

```java
.requestMatchers("/api/v1/admin/**").hasRole("ADMIN")
```

## 六、前端错误上报

实现类：`chat-common/.../controller/FrontendErrorController.java`

**接口**：`POST /api/v1/frontend-error` (无需登录)

**上报来源**：
1. `window.onerror` — 全局未捕获错误
2. `window.unhandledrejection` — 未处理的 Promise 拒绝
3. `ErrorBoundary.componentDidCatch` — React 渲染异常

**处理**：记录到后端日志 (WARN 级别)，带堆栈信息

## 七、密钥管理

| 密钥类型 | 存储方式 | 位置 |
|---------|---------|------|
| JWT 签名密钥 | 配置文件 | `application.yml` 或环境变量 |
| LLM API Key | 加密存储 | MySQL `model_configs` 表 `api_key_encrypted` 字段 |
| 数据库密码 | 环境变量 | `DB_USERNAME` / `DB_PASSWORD` in `.env` |

---

## 八、WebSocket 安全

- WebSocket 端点：`/ws/chat`
- 连接时携带 JWT (query param 或 STOMP header)
- 不需要额外鉴权（公开群聊的 WebSocket 也允许匿名连接）
- SockJS 心跳维持连接状态
