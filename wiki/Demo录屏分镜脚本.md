# Demo 录屏分镜脚本（提交视频用）

> 适用：GOAI 要求提交 Demo 视频的场景。
> 建议时长：3 分钟（评审注意力极限），可通过剪辑压缩。
> 建议工具：macOS 用 QuickTime 录屏 / OBS（免费开源），剪辑用剪映或 iMovie。
> 原则：**录屏真实操作 + 精简剪辑 + 加字幕/旁白**，别一镜到底（会暴露等待时间）。

## 录制要点

### 录制前准备（重要）

1. **清理浏览器**：关掉多余标签页、书签栏、其他窗口，避免录进无关内容
2. **调好窗口**：浏览器全屏，分辨率建议 1920×1080
3. **准备演示文档**：RAG 场景需要提前上传一个 PDF 到知识库（录前传好，录时直接提问，省等待）
4. **预热模型**：录制前先把要演示的请求跑一遍，让模型「热身」，录制时响应更快
5. **关闭通知**：系统通知、微信、钉钉弹窗全部关掉，避免录进隐私

### 录制中要点

1. **鼠标移动放慢**：录屏里鼠标乱晃很显眼，移动要平滑、有目的
2. **操作前停顿半秒**：每个点击前停一下，方便剪辑
3. **别说话时录**：建议「先录画面 + 后期配音」，比「边录边说」更容易控制质量
4. **每镜单独录**：按分镜表分段录，后期拼接，比一镜到底容错率高

### 后期剪辑要点

1. **剪掉所有等待时间**：模型响应的等待直接剪掉，用「画面跳变」自然过渡
2. **加字幕**：关键操作加字幕，静音观看也能看懂（评审可能静音快速浏览）
3. **配 BGM 或不配**：技术 demo 建议轻 BGM 或不配，避免喧宾夺主
4. **时长压到 3 分钟**：超过 3 分钟的部分果断剪掉，评委没有耐心

## 常见翻车点（务必避免）

| 翻车点 | 后果 | 规避 |
|---|---|---|
| 录进浏览器其他标签 | 显得不专业 | 录制前清理浏览器 |
| 模型响应超时，画面卡住 | 评委以为「挂了」 | 剪辑掉等待，或预热模型 |
| 录进系统通知/聊天弹窗 | 泄漏隐私 | 关闭所有通知 |
| 一镜到底没剪辑 | 冗长拖沓 | 分段录 + 剪辑 |
| 没有字幕 | 静音看不懂 | 关键步骤加字幕 |

## 备选：如果时间紧，可用「截图轮播 + 配音」

如果来不及录屏 + 剪辑，退而求其次的方案：
- 用几张关键截图（首页、辩论场、Multi-Agent、RAG、知识图谱）+ 旁白配音 + 转场，做成一个「幻灯片式 demo 视频」
- 效果不如真实录屏，但能交，且风险低（不会录进隐私、不会卡住）
