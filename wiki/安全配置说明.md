# 安全配置说明

> JWT 鉴权、接口白名单、IP 限流、内容安全的完整说明

---

## 一、安全体系总览

```
请求进入
    │
    ▼
IpRateLimitInterceptor (滑动窗口限流)
    ├─ 同 IP 短时间内请求过多 → 自动拉黑
    └─ UA 过滤可疑爬虫
    │
    ▼
JwtAuthenticationFilter (JWT 鉴权)
    ├─ 提取 Authorization: Bearer xxx
    ├─ 验证 JWT 签名和有效期
    └─ 未通过 → 401
    │
    ▼
ContentSafetyService (内容安全)
    └─ 阿里云内容安全检测 → 命中敏感词拒绝
    │
    ▼
业务 Controller
```

## 二、JWT 鉴权

### 2.1 配置

实现类：`chat-common/.../security/JwtUtil.java`

| 配置项 | 说明 |
|--------|------|
| Token 格式 | `Authorization: Bearer <token>` |
| 签名算法 | HMAC-SHA256 |
| Token 存储 | 前端 `localStorage.auth_token` |
| 密钥强度 | 必须 ≥ 32 字节（弱密钥拒绝启动，见 2.4） |

### 2.2 前端拦截

`main.jsx` 中全局 axios 401 拦截器：
```javascript
// 任意接口返回 401 时
axios.interceptors.response.use(
  response => response,
  error => {
    if (error.response?.status === 401) {
      localStorage.removeItem('auth_token');
      localStorage.removeItem('auth_user');
      window.dispatchEvent(new Event('auth-changed'));
    }
    return Promise.reject(error);
  }
);
```

### 2.3 登录拦截的页面

以下页面未登录时拦截导航，弹出登录框：
- `/personal` — 个人对话空间
- `/treehole` — 情绪树洞
- `/profile` — 个人信息

### 2.4 弱密钥校验（2026-08 新增）

`JwtUtil` 在启动时校验 `jwt.secret` 强度：**少于 32 字节直接抛 `IllegalStateException` 拒绝启动**，防止弱密钥被暴力破解。

```bash
# 生成符合要求的强密钥
openssl rand -base64 48
```

> 生产环境 `.env` 中 `JWT_SECRET` 需同步更新为 ≥32 字节（当前 40 字节，符合要求）。

### 3.1 无需登录的公开接口

```java
// 认证相关
.requestMatchers("/api/v1/auth/**").permitAll()

.requestMatchers("/api/v1/messages/**").permitAll()

// 监控面板（独立密码验证）
```

## 四、限流机制

### 4.1 IP 访问限流（网关层）

实现类：`chat-common/.../interceptor/IpRateLimitInterceptor.java`

| 配置 | 说明 |
|------|------|
| 算法 | 滑动窗口 |
| 触发条件 | 同 IP 短时间大量请求 |
| 处理方式 | 自动拉黑 + UA 过滤（拦截可疑爬虫 UA） |

### 4.2 SQL 执行台限流（2026-08 新增）

实现类：`chat-games/.../SqlExecutorController.java`

| 配置 | 说明 |
|------|------|
| 登录失败锁定 | 同一 IP 连续失败 ≥ 5 次 → 锁定 15 分钟，返回 429 并提示剩余锁定分钟 |
| 执行频率 | 同一 IP 滑动窗口，每分钟最多 30 次 |
| 危险关键字 | 拦截 `OUTFILE` / `DUMPFILE` / `LOAD_FILE` / `SLEEP` / `BENCHMARK` 等 |
| 多语句 | 包含 `;` 的多语句直接拒绝 |

### 4.3 媒体生成限流（2026-08 新增）

实现类：`chat-media/.../MediaGenController.java`（`RateLimitService`）

| 配置 | 说明 |
|------|------|
| 限流维度 | 用户级（按 userId） |
| 处理方式 | 超限返回 429 + `retry_after`（重试等待秒数） |
| 覆盖接口 | 图片/视频/3D 等生成类接口 |

## 五、内容安全

实现类：`chat-common/.../service/ContentSafetyService.java`

| 配置 | 说明 |
|------|------|
| 服务商 | 阿里云内容安全 API |
| 检测时机 | ① 用户发送消息前（输入侧）② LLM 生成完整答案后（输出侧，chat-core） |
| 处理方式 | 命中敏感词 → 拒绝请求，返回提示 |
| 异常策略 | **fail-close**：检测服务异常时不放行，返回 `SYSTEM_ERROR` 标签由调用方拒绝（避免敏感内容绕过检测） |

**输出侧检测**（chat-core `ChatProcessor`）：
- 在完整答案推送后，对 LLM 生成内容做一次异步内容安全检测
- 命中敏感内容时：记录告警日志 + **跳过缓存写入与记忆/事实保存**，防止敏感内容被复用或污染后续链路
- 说明：流式输出已实时推送，输出检测不阻断已推送内容（流式架构固有特性），而是作用于缓存/记忆等复用链路

## 六、前端错误上报

实现类：`chat-common/.../controller/FrontendErrorController.java`

**接口**：`POST /api/v1/frontend-error` (无需登录)

**上报来源**：
1. `window.onerror` — 全局未捕获错误
2. `window.unhandledrejection` — 未处理的 Promise 拒绝
3. `ErrorBoundary.componentDidCatch` — React 渲染异常

**处理**：记录到后端日志 (WARN 级别)，带堆栈信息

## 八、参数校验与上传限制（2026-08 新增）

### 8.1 DTO 参数校验

登录/注册等接口使用 `@Valid` + DTO（`LoginRequest` / `RegisterRequest`）统一校验：

| 校验项 | 规则 |
|-------|------|
| 用户名 | `@NotBlank`、`@Size(min=3, max=50)` |
| 密码 | `@NotBlank`、`@Size(min=6, max=50)` |
| 其他字段 | 按接口语义配置（邮箱格式、长度上限等） |

校验失败返回 400 + 具体字段错误，不再手写长度判断。

### 8.2 上传大小限制

全模块（chat-web / chat-core / chat-games / chat-media）统一配置：

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 10MB
      max-request-size: 10MB
```

超限请求返回 413，防止超大文件拖垮服务。

### 8.3 上传类型校验（扩展名白名单）

`AttachmentController` 上传前校验：

| 校验项 | 规则 |
|-------|------|
| 空文件 | 拒绝（400） |
| 扩展名白名单 | 仅允许图片/文档/音视频/压缩包等安全类型（`.jpg/.png/.pdf/.docx/.mp4/.zip` 等），拒绝脚本/可执行文件（`.sh/.exe/.jar` 等）及无扩展名文件 |
| 大小兜底 | 代码层二次校验 10MB 上限（防绕过 Nginx/容器 multipart 限制） |
| 路径穿越 | 存储文件名使用 `UUID + 白名单扩展名`，丢弃原始文件名 |

---

### 8.4 OSS 转存 SSRF 防护

`OssService.transferToOss` 在下载外部 URL 前校验：

- 仅允许 `http`/`https` 协议
- 拒绝 localhost、回环、链路本地、站点本地（内网网段）、组播地址
- DNS 重绑定防护：解析出的所有地址中任一为内网即拒绝

防止利用 OSS 转存功能探测/攻击内网服务。

## 九、WebSocket 安全

- WebSocket 端点：`/ws/chat`（游戏独立端点 `/ws/games`）
- **握手鉴权**：SockJS 无法自定义 Header，JWT 经 query 参数 `token` 传递；有效 token 会绑定真实 `userId`（以 token 的 `uid` claim 为准，忽略可被伪造的 `userId` query 参数）
- **匿名连接**：未携带 token 的匿名连接（如首页在线人数、监控面板）允许握手，但只能订阅公开广播 topic（如 `/topic/online-count/*`）
- **订阅级鉴权**（`ChannelInterceptor`）：订阅用户私有 topic（`/topic/user.*`、`/topic/debate.*`、`/topic/treehole.*`）时强制校验——必须已登录且 token 中的 userId 与 topic 中的 userId 一致，否则拒绝订阅（防横向越权订阅他人消息）
- SockJS 心跳维持连接状态
