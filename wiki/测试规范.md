### 3.2 结构规范 (AAA 模式)

```java
@Test
void shouldReturnCachedResultWhenAvailable() {
    // Arrange - 准备测试数据
    String query = "什么是 AI?";
    when(cacheService.get("query:123")).thenReturn("AI 是人工智能的缩写");

    // Act - 执行被测方法
    String result = chatService.answer("123", query);

    // Assert - 验证结果
    assertEquals("AI 是人工智能的缩写", result);
    verify(cacheService).get("query:123");
    verify(llmClient, never()).call(any());
}
```

### 3.3 禁止写法

```java
// ❌ 空壳测试 - 无意义

    assertNotNull("test");

@Test

    var conn = DriverManager.getConnection("jdbc:mysql://rds...");

// ✅ 正确：mock 外部依赖
@Test

    when(userRepository.findById(1L)).thenReturn(Optional.of(mockUser));
```

### 3.4 Mock 策略

| 场景 | 策略 |
|------|------|
| Repository/DAO | 全部 mock |
| 外部 HTTP 调用 | 全部 mock (WireMock / Mockito) |
| LLM API 调用 | 全部 mock，避免产生费用 |
| Redis 缓存 | mock (RedisTemplate / StringRedisTemplate) |
| RabbitMQ | mock (RabbitTemplate / SimpMessagingTemplate) |
| WebSocket 管理 | mock (WebSocketSessionTracker) |
| 纯逻辑 Util 类 | 不需要 mock |
| 值对象/DTO | 不需要 mock |

> **Mock 框架**: Mockito 5.14.2 + ByteBuddy 1.15.11 (兼容 JDK 26)
> Mockito 5.x 内置支持 mock final 类/方法，**不再需要** `mockito-inline` 依赖。
> pom.xml 中统一管理 `mockito.version` 和 `byte-buddy.version` 版本号。

### 5.1 何时写集成测试

### 5.2 写法示例

```java
@SpringBootTest(webEnvironment = WebEnvironment.RANDOM_PORT)
@AutoConfigureMockMvc
class ChatControllerIntegrationTest {

    @Autowired
    private MockMvc mockMvc;

    @MockBean
    private CoreClient coreClient;  // mock 下游依赖

    @Test
    void sendMessage_validRequest_returns200() throws Exception {
        when(coreClient.chat(any())).thenReturn(Map.of("reply", "你好"));

        mockMvc.perform(post("/api/v1/chat/send")
                .contentType(MediaType.APPLICATION_JSON)
                .content("""
                    {"question":"你好","modelId":1}
                    """))
            .andExpect(status().isOk())
            .andExpect(jsonPath("$.reply").value("你好"));
    }
}
```

### 5.3 Multi-Agent 工作流生产测试套件（2026-08 新增）

**脚本**：`scripts/test-multiagent-suite.sh`（运行于 Milvus 服务器，`bash /opt/app/test-multiagent-suite.sh [--quick]`）

覆盖 Multi-Agent 并行工作流全链路（web→core→RabbitMQ→Worker→收敛→DB）：

| 用例 | 场景 | 断言 |
|------|------|------|
| T01 | 单请求并行链路（经 web 全链路） | queued → 分发 9 子任务 → 收敛 answerLen ≤1000 → DB done（4 项） |
| T02 | 简单问题不拆解 | 不触发拆解 + 普通流式 DB done（2 项） |
| T03 | 并发限流降级（20 并发） | 8 并行 + 12 降级 = 20 全有去向；并行 ≤10；全部收敛（3 项） |
| T04 | manual ack 可靠性 | 子任务执行完成数 == 分发数（零丢失） |
| T05/T06 | 输出压缩 + DB 终态 | 汇总本套件所有 web 落库请求终态 done（2 项） |

- 全量目标：**PASS=12 / FAIL=0**（2026-08-13 实测通过）
- `--quick` 跳过 T03/T04（避免耗时并发场景）
- 前置清理：Redis `agent:workflow:active` 应归零（上一轮中断测试可能遗留，脚本启动前 `redis-cli del agent:workflow:active`）

### 5.4 @SpringBootTest 集成测试落地（2026-08-13 新增）

**测试类**（`chat-web/src/test/java/com/example/chat/`）：

| 测试类 | 用例数 | 覆盖链路 |
|------|:---:|------|
| `MessageFlowIntegrationTest` | 6 | 消息全链路（限流→用户→落库→广播→AI）、`ai_answer=false` 不触发、429+retry_after、敏感词 400、消息列表透传、在线人数聚合 |
| `DebateFlowIntegrationTest` | 4 | 辩论全链路（安全→落库→启动）、敏感词 400、rounds 钳制 1-10（20→10/0→1/非法→3）、model_count 钳制 3-6、mode 透传 |

**技术栈**：
- `@SpringBootTest(RANDOM_PORT)` + `TestRestTemplate` — **不能用 MockMvc**（`WebSocketConfig` 的 `ServletServerContainerFactoryBean` 需要真实 Servlet 容器）
- H2 `MODE=MySQL` 内存库替代 MySQL（`application-test.yml`，`DB_CLOSE_DELAY=-1` 保证上下文复用）
- `spring.autoconfigure.exclude=RabbitAutoConfiguration` + `app.module.core=false`（排除 `RabbitConfig`/`IdleSessionCleanupTask`）+ Nacos 关闭
- 7 个 `@MockBean`：`CoreClient`（下游 HTTP）、`RateLimitChecker`（Redis）、`ContentSafetyService`（阿里云）、`BroadcastService`（RabbitMQ/WebSocket）、`WebSocketSessionTracker`、`OnlineCountRedisService`、`OnlineCountScheduler`

**关键坑记录**：
1. **UA 黑名单**：`IpRateLimitInterceptor` 拦截 `Java/`、`HttpClient` 等 UA → 测试必须带浏览器 UA 头
2. **限流 key 前缀**：`rate:user:`（用户维度）与 `ip:rate:`（拦截器维度）分别 stub，避免 429 用例误伤全局限流
3. **`getLabelHint` 返回 null 陷阱**：mock 需返回固定提示，否则 `ApiResponse.error` 内部 `Map.of` 抛 NPE → 500
4. **不可 mock `StringRedisTemplate`**：`WebSocketSessionTracker` 构造器立即写 Redis，mock 返回 null 导致拦截器 NPE → 保留本机真实 Redis

**运行方式**：`mvn -pl chat-web -am test -Dtest=MessageFlowIntegrationTest,DebateFlowIntegrationTest -Dsurefire.failIfNoSpecifiedTests=false`
